Numfit

Home Guides Docs Github

Numfit is a JavaScript library for numerical interpolation, extrapolation, scattered-data modeling, and regression. It supports structured tensor grids, triangles, tetrahedra, N-dimensional simplexes, piecewise meshes and splines, Hermite curves, inverse-distance weighting, radial basis functions, robust regression, TypeScript declarations, and worker-backed batch evaluation in Node and modern browsers.

Interpolation & Extrapolation

Use fixed 1D, 2D, and 3D interpolators, generalized polynomial tensor grids, or simplex cells for unstructured triangle and tetrahedral data.

Regression Models

Fit polynomial, linear, ridge, weighted, Huber, and RANSAC regression models, then inspect RMSE, R-squared, AIC, BIC, leverage, and Cook's distance.

Meshes, Splines, and Samplers

Combine mixed interpolators into meshes or splines, sample them with grids, slices, random points, Latin hypercubes, Poisson disks, adaptive curves, or async streams.
