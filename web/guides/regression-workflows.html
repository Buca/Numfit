Regression Workflows

Edit

This guide shows a practical regression workflow: fit a model, inspect diagnostics, handle outliers, and select model options with cross-validation.

Fit and inspect


import { PolynomialRegression } from 'numfit';

const fit = new PolynomialRegression({
	positions,
	values,
	degree: 2,
	normalize: 'standard'
});

console.log( fit.rmse() );
console.log( fit.r2() );
console.log( fit.summary() );

Outlier-resistant fitting


const robust = new PolynomialRegression({
	positions,
	values,
	degree: 2,
	robust: 'huber',
	delta: 1,
	normalize: 'standard'
});

const influence = robust.influence();

For harder outliers, use RANSACRegression to fit from an inlier consensus set.

Model selection


import { PolynomialRegression, crossValidateRegression } from 'numfit';

const selected = crossValidateRegression({
	model: PolynomialRegression,
	positions,
	values,
	degree: [ 1, 2, 3, 4 ],
	regularization: [ 0, 1e-6, 1e-3 ],
	normalize: [ false, 'standard' ],
	folds: 5,
	metric: 'mse'
});

selected.bestModel.evaluate( 4 );
