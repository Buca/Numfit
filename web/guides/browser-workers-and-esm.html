Browser Workers and ESM

Edit

Modern Numfit projects can import the ESM build and use mapAsync in browsers. Large typed-array batches are split across module workers when workers are available.

ESM import


<script type="module">
	import { Tricubic } from './Numfit.module.js';

	const values = await tricubic.mapAsync( positions, {
		workers: 4,
		workerUrl: new URL( './Numfit.worker.js', import.meta.url )
	});
</script>

Testing browser support


npm run test:browser:install
npm run test:browser

The browser smoke test verifies worker-backed mapping, typed-array outputs, and browser ESM regression exports.
