TypeScript, ESM, and Workers

Edit

Numfit ships TypeScript declarations, modern package exports, browser ESM builds, and worker-backed mapping for large batches.

Modern imports


import {
	Linear,
	PolynomialRegression,
	Spline
} from 'numfit';

Browser module build


<script type="module">
	import { Linear } from './build/Numfit.module.js';
</script>

Keep Numfit.worker.js and Numfit.mesh.worker.js next to the module build, or pass custom worker URLs to mapAsync.
