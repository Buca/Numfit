Polynomial and Multi Variants

Edit

The polynomial classes generalize the fixed linear, quadratic, and cubic interpolators. Use them when you need arbitrary degree, arbitrary dimensionality, or N-dimensional hyperbox interpolation.

Classes

PolynomialOne-dimensional polynomial interpolation with arbitrary degree.
MultilinearN-dimensional linear tensor-product interpolation.
MultiquadraticN-dimensional quadratic tensor-product interpolation.
MulticubicN-dimensional cubic tensor-product interpolation.
MultipolynomialN-dimensional tensor-product interpolation with arbitrary degree.

Example


import { Multipolynomial } from 'numfit';

const surface = new Multipolynomial(
	new Float64Array([ 0,0, 1,1, 2,2 ]),
	new Float64Array([
		0, 1, 4,
		1, 2, 5,
		4, 5, 8
	]),
	1,
	2,
	2
);

surface.evaluate([ .5, .5 ]);
