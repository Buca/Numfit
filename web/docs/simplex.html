Simplex Interpolation

Edit

Simplex interpolation evaluates unstructured linear cells such as triangles, tetrahedra, and generic N-dimensional simplexes. Use it when your domain is not a rectangular grid.

Classes

SimplexLinearGeneric N-dimensional simplex interpolation.
TriangleLinearTwo-dimensional triangle interpolation.
TetrahedralLinearThree-dimensional tetrahedron interpolation.

Example


import { TriangleLinear } from 'numfit';

const triangle = new TriangleLinear(
	new Float64Array([ 0,0, 1,0, 0,1 ]),
	new Float64Array([ 10, 20, 30 ])
);

triangle.contains([ .25, .25 ]);
triangle.getWeights([ .25, .25 ]);
triangle.evaluate([ .25, .25 ]);
