Scattered Data

Edit

Scattered-data interpolators work from arbitrary sample locations rather than structured grids or explicit mesh cells.

Inverse Distance Weighting


import { InverseDistanceWeighting } from 'numfit';

const idw = new InverseDistanceWeighting({
	positions,
	values,
	variables: 2,
	power: 2,
	radius: .05,
	neighbors: 16,
	index: 'grid',
	empty: 'nearest'
});

Radial Basis Functions


import { RadialBasisFunction } from 'numfit';

const rbf = new RadialBasisFunction({
	positions,
	values,
	variables: 2,
	kernel: 'thin-plate',
	smoothing: 1e-6
});

Supported kernels include gaussian, multiquadric, inverse-multiquadric, linear, cubic, and thin-plate.
