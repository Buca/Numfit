Regression

Edit

Regression models fit approximate functions to sampled data. Numfit supports polynomial, linear, ridge, weighted, Huber, and RANSAC regression.

Classes and helpers

PolynomialRegressionTotal-degree polynomial least squares.
LinearRegressionConvenience model with degree: 1.
RidgeRegressionPolynomial regression with regularization.
RANSACRegressionRobust wrapper that finds an inlier consensus set.
crossValidateRegressionK-fold grid search for model selection.

Example


import {
	PolynomialRegression,
	crossValidateRegression
} from 'numfit';

const fit = new PolynomialRegression({
	positions,
	values,
	degree: 2,
	weights,
	robust: 'huber',
	normalize: 'standard'
});

fit.rmse();
fit.summary();
fit.influence();

const selected = crossValidateRegression({
	model: PolynomialRegression,
	positions,
	values,
	degree: [ 1, 2, 3 ],
	regularization: [ 0, 1e-3 ],
	normalize: [ false, 'standard' ],
	folds: 5
});
