Hermite Interpolation

Edit

Hermite interpolators use endpoint values and derivatives. CubicHermite uses first derivatives, while QuinticHermite also uses second derivatives.

Example


import { CubicHermite, QuinticHermite } from 'numfit';

const cubic = new CubicHermite({
	positions: [ 0, 1 ],
	values: [ 0, 1 ],
	derivatives: [ 1, 0 ]
});

const quintic = new QuinticHermite({
	positions: [ 0, 1 ],
	values: [ 0, 1 ],
	derivatives: [ 1, 0 ],
	secondDerivatives: [ 0, 0 ]
});
