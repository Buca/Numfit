Meshes and Splines

Edit

InterpolationMesh combines many interpolators into one piecewise interpolator. Mesh and Spline are aliases for the same class, with Spline commonly used for one-dimensional interval curves.

Construction helpers

  • InterpolationMesh.fromIntervals(options)
  • InterpolationMesh.fromTriangles(positions, values, indices, options)
  • InterpolationMesh.fromTetrahedra(positions, values, indices, options)
  • InterpolationMesh.fromSimplexes(positions, values, indices, options)

Examples


import { CubicHermite, Linear, Spline } from 'numfit';

const linearSpline = Spline.fromIntervals({
	type: Linear,
	positions: [ 0, 1, 2, 3 ],
	values: [ 0, 1, 0, 2 ]
});

const hermiteSpline = Spline.fromIntervals({
	type: CubicHermite,
	positions: [ 0, 1, 2, 3 ],
	values: [ 0, 1, 0, 2 ],
	derivatives: 'akima',
	index: 'grid'
});

Use { blending: 'weighted' } when overlapping cells should be smoothly blended instead of using the first matching cell.
